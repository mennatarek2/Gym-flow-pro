Offers & Promotions

One place for membership and product deals. A promo code is only an optional way to redeem an offer — not a separate product.

Offer → rules → visibility → redemption (auto or code)

Conceptual model (preview)

Owners manage Offers. Promo codes are nested under redemption — so you never maintain two promotion systems for memberships vs products.

Evaluate before implementation

  1. Is Offers & Promotions the right replacement for Promo Codes?
  2. Is the Admin creation flow intuitive for a gym owner?
  3. Are Membership vs Product offers clear?
  4. Is Member App presentation compelling?
  5. Is Automatic vs Promo Code redemption understandable?
  6. Does the UX fit HyMotion (lime / charcoal)?
