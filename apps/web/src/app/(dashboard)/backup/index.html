Restore this copy

  1. Tell the desk to stop selling and checking in. This PC will be offline for a few minutes.
  2. Click Open Restore. Allow Windows if it asks.
  3. In HyMotion Backup, type RESTORE and wait. HyMotion opens again when it finishes.

If nothing opens: Start menu → HyMotion Backup.
